Bloggen auf CloudCannon unterstützt **Snippets**: reichhaltige, interaktive Komponenten jenseits von Standard-Markdown. Diese MDX-Komponenten ermöglichen anspruchsvolle Layouts, eingebettete Funktionen und mehr Beteiligung der Leserschaft — ohne dass für jeden Beitrag eigens entwickelt werden muss.

Dieser Beitrag zeigt eine Auswahl von Beispiel-Snippets, jeweils mit Platzhaltertext. Sie können auch <a href="https://cloudcannon.com/documentation/developer-articles/snippets-using-mdx-components/" target="_blank" rel="noopener">eigene Snippets mit MDX-Komponenten bauen</a>.

## CTA Center

Das Snippet CTA Center erzeugt mitten im Inhalt einen optisch abgesetzten Handlungsaufruf, mit vielen Optionen für Farbe, Hintergrund und Darstellung.

<CtaCenter
  heading={"<p>Main heading text for the CTA Center section.</p>"}
  id="cta-center"
  eyebrowIcon={{
    _component: "building-blocks/core-elements/icon",
    name: "eye",
    size: "lg",
    color: "default",
    background: true,
    alignmentHorizontal: "center",
  }}
  eyebrowText="Optional label displayed above the CTA Center heading."
  subtext="Optional subtext displayed beneath the CTA Center heading."
  buttonSections={[
    {
      _component: "building-blocks/core-elements/button",
      text: "Button text with optional icon",
      hideText: null,
      link: "",
      iconName: "chat-bubble-bottom-center",
      iconPosition: "after",
      variant: "primary",
      size: "md",
    },
  ]}
  maxContentWidth="xl"
  paddingVertical="2xl"
  colorScheme="light"
  backgroundColor="brand-linear-gradient-reverse"
  contentBackground={true}
  rounded={true}
/>

## Table

Das erweiterte Snippet Table liefert eine gestaltete Tabelle, mit Spaltenköpfen, Abschnittsbezeichnungen für Zeilengruppen und so vielen Zeilen und Spalten, wie auf Ihre Seite passen.

<Table
  heading={"<p>Table heading</p>"}
  id="table"
  eyebrowIcon={{
    _component: "building-blocks/core-elements/icon",
    name: "table-cells",
    size: "lg",
    color: "brand-gradient",
    background: true,
    alignmentHorizontal: "center",
  }}
  eyebrowText="Optional label displayed above the table's heading."
  subtext="Optional subtext displayed beneath the table's heading."
  table={{
    headers: [
      { hideText: true, text: "Header" },
      { text: "Header One" },
      { text: "Header Two" },
      { text: "Header Three" },
    ],
    sections: [
      {
        sectionName: "Section One",
        rows: [
          { cells: ["Cell one", "Cell two", "Cell three"] },
          { cells: ["Cell one", "Cell two", "Cell three"] },
        ],
      },
      {
        sectionName: "Section Two",
        rows: [
          { cells: ["Cell one", "Cell two", "Cell three"] },
          { cells: ["Cell one", "Cell two", "Cell three"] },
        ],
      },
      { sectionName: "Section Three", rows: [{ cells: ["Cell one", "Cell two", "Cell three"] }] },
    ],
  }}
  maxContentWidth="xl"
  paddingVertical="md"
  colorScheme="inherit"
  backgroundColor="none"
  verticalOffset={{ size: "none", direction: "front" }}
/>
