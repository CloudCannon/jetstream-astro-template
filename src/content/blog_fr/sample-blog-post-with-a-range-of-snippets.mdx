Le blog sur CloudCannon prend en charge les **Snippets** : des composants interactifs riches qui vont au-delà du Markdown standard. Ces composants MDX permettent des mises en page élaborées, des fonctionnalités intégrées et une expérience plus engageante, sans développement sur mesure pour chaque article.

Cet article présente un éventail de Snippets d'exemple, avec du texte de remplacement pour chacun. Vous pouvez aussi <a href="https://cloudcannon.com/documentation/developer-articles/snippets-using-mdx-components/" target="_blank" rel="noopener">créer vos propres Snippets à l'aide de composants MDX</a>.

## CTA Center

Le Snippet CTA Center crée un bloc d'appel à l'action visuellement distinct au fil de votre contenu, avec tout un éventail d'options de couleur, d'arrière-plan et de présentation.

<CtaCenter
  heading={"<p>Main heading text for the CTA Center section.</p>"}
  id="cta-center"
  eyebrowIcon={{
    _component: "building-blocks/core-elements/icon",
    name: "eye",
    size: "lg",
    color: "default",
    background: true,
    alignmentHorizontal: "center",
  }}
  eyebrowText="Optional label displayed above the CTA Center heading."
  subtext="Optional subtext displayed beneath the CTA Center heading."
  buttonSections={[
    {
      _component: "building-blocks/core-elements/button",
      text: "Button text with optional icon",
      hideText: null,
      link: "",
      iconName: "chat-bubble-bottom-center",
      iconPosition: "after",
      variant: "primary",
      size: "md",
    },
  ]}
  maxContentWidth="xl"
  paddingVertical="2xl"
  colorScheme="light"
  backgroundColor="brand-linear-gradient-reverse"
  contentBackground={true}
  rounded={true}
/>

## FAQ Section

## Table

Le Snippet Table enrichi produit un tableau mis en forme, avec en-têtes de colonnes, libellés de section pour les groupes de lignes, et autant de lignes et de colonnes que votre page peut en accueillir.

<Table
  heading={"<p>Table heading</p>"}
  id="table"
  eyebrowIcon={{
    _component: "building-blocks/core-elements/icon",
    name: "table-cells",
    size: "lg",
    color: "brand-gradient",
    background: true,
    alignmentHorizontal: "center",
  }}
  eyebrowText="Optional label displayed above the table's heading."
  subtext="Optional subtext displayed beneath the table's heading."
  table={{
    headers: [
      { hideText: true, text: "Header" },
      { text: "Header One" },
      { text: "Header Two" },
      { text: "Header Three" },
    ],
    sections: [
      {
        sectionName: "Section One",
        rows: [
          { cells: ["Cell one", "Cell two", "Cell three"] },
          { cells: ["Cell one", "Cell two", "Cell three"] },
        ],
      },
      {
        sectionName: "Section Two",
        rows: [
          { cells: ["Cell one", "Cell two", "Cell three"] },
          { cells: ["Cell one", "Cell two", "Cell three"] },
        ],
      },
      { sectionName: "Section Three", rows: [{ cells: ["Cell one", "Cell two", "Cell three"] }] },
    ],
  }}
  maxContentWidth="xl"
  paddingVertical="md"
  colorScheme="inherit"
  backgroundColor="none"
  verticalOffset={{ size: "none", direction: "front" }}
/>
